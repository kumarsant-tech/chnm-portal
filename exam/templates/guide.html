CHNM CGT — प्रश्न पत्र अपलोड

प्रश्न पत्र अपलोड करने की पूरी गाइड

यह फोल्डर ही आपका अपलोड फोल्डर है। यहाँ से नमूना फाइल डाउनलोड करें, अपने प्रश्न भरें और एडमिन पैनल में अपलोड करके प्रीव्यू करें। CSV, Excel (XLSX), JSON और HTML — चारों चलते हैं।

CSV नमूना10 तैयार Trade Theory प्रश्न — तुरंत आयात योग्य CSV खाली टेम्पलेटहेडर तैयार — अपने प्रश्न भरें Excel टेम्पलेटXLSX — Excel में खोलकर भरें HTML नमूनातालिका वाली HTML फाइल JSON नमूनातकनीकी उपयोग के लिए

1. प्रश्न पत्र अपलोड करें

1
एडमिन पैनल खोलें: admin.html → प्रश्न बैंक।
2
आयात करें बटन दबाएँ। डिफ़ॉल्ट विषय चुनें (जैसे Trade Theory) और चाहें तो सीधे किसी परीक्षा को चुनें।
3
CSV / XLSX / HTML फाइल चुनें या खींचकर छोड़ें। स्क्रीन पर पहली 12 पंक्तियाँ, विषय, विकल्प, सही उत्तर और अंक दिखेंगे — यही प्रीव्यू है।
4
गलत पंक्तियाँ लाल चेतावनी में दिखेंगी। ठीक करके फाइल दोबारा चुनें, फिर आयात करें दबाएँ। डुप्लीकेट प्रश्न (वही Question ID या वही प्रश्न टेक्स्ट) छोड़ दिए जाते हैं।

एक बार में अधिकतम 1000 प्रश्न। आयात के बाद भी प्रश्न बैंक में जाकर किसी प्रश्न को बदला जा सकता है।

2. फाइल में कॉलम कैसे भरें

कॉलमक्या लिखें
Question IDअपना यूनिक कोड, जैसे TT-PAPER-01। खाली छोड़ें तो सिस्टम अपने-आप बना देगा।
Subjectविषय का नाम या कोड — Trade Theory / TT, TM, Soft Skills, Networking आदि।
Questionपूरा प्रश्न (हिंदी, अंग्रेज़ी या दोनों)।
Option A–Dचार विकल्प अलग-अलग कॉलम में। कम से कम दो विकल्प जरूरी हैं।
Correct Answerसिर्फ A, B, C या D (या विकल्प का नंबर 1–4)।
Marksप्रति प्रश्न अंक, जैसे 1 या 2। खाली छोड़ें तो परीक्षा का डिफ़ॉल्ट लगेगा।
Negative Marksगलत उत्तर पर कटौती। शून्य या खाली = कोई कटौती नहीं।
Explanationउत्तर की व्याख्या — परिणाम में छात्र को दिखती है (जब Answer Key खोली हो)।
Imageवैकल्पिक चित्र का लिंक, जैसे img/circuit.png। खाली छोड़ सकते हैं।

सुझाव: पुराना पेपर Word/Excel में है तो उसे CSV में “Save As” करें और ऊपर वाले हेडर नाम इस्तेमाल करें। HTML पेपर में केवल एक <table> रखें — बाकी सारा टेक्स्ट अनदेखा हो जाता है।

3. पेपर सेट करें (एडमिन)

  1. परीक्षाएँ → नई परीक्षा: शीर्षक, कोड, विषय, समय (मिनट), पास %, प्रकार (Practice / Final), तारीख और प्रयास सीमा भरें।
  2. प्रश्न चुनें और प्रीव्यू से पूरा पेपर देखें। क्रम/अंक ठीक होने पर ड्राफ्ट में सेव करें।
  3. Lock करें — पेपर का स्नैपशॉट और हैश बन जाता है, फिर बदलाव नहीं होते।
  4. Publish करें। अब छात्र अपने मोबाइल पर लॉगिन करके परीक्षा दे सकते हैं।

Published परीक्षा में प्रश्न बदलने हों तो पहले Unpublish करें — परिणाम सुरक्षित रहते हैं।

4. छात्र मोबाइल पर परीक्षा देगा

  1. छात्र पहली बार register.html पर नाम, मोबाइल, ईमेल और ट्रेड भरकर रजिस्ट्रेशन करता है।
  2. उसे CHNM से शुरू होने वाला ID मिलता है, जैसे CHNM12 — यही उसकी पहचान है।
  3. लॉगिन के लिए वही CHNM ID और रजिस्टर्ड मोबाइल नंबर डालता है।
  4. अपनी परीक्षा खोलकर निर्देश पढ़ता है और शुरू करता है। उत्तर अपने-आप सेव होते हैं; समय खत्म होने पर परीक्षा स्वतः जमा हो जाती है।

5. परिणाम बाद में प्रकाशित करें

Final परीक्षा का परिणाम छात्र को तब तक नहीं दिखता जब तक आप प्रकाशित न करें।

  1. परिणाम → परीक्षा चुनें → Release Results।
  2. चाहें तो Show Answers चालू करें — छात्र को सही उत्तर और व्याख्या दिखेगी।
  3. छात्र अपने डैशबोर्ड पर स्कोर, प्रतिशत और पास/फेल देख सकेगा।

Practice परीक्षा का परिणाम तुरंत दिखता है — उसे Release की जरूरत नहीं।
